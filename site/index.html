vhid

A virtual keyboard and mouse for macOS, driven from the command line or by an AI agent.

macOS treats vhid's input as coming from hardware, so a script or an agent can type and click where software-generated input is blocked, such as the lock screen and password prompts, without the Accessibility permission. Its companion, eyes, reads the screen and prints where things are, as the points vhid click takes.

Install

You need macOS 15 or later, on Apple silicon or Intel, and an administrator account. With Homebrew:

brew install --cask promptctl/tap/vhid

Or download the pkg from the Releases page and open it.

One step is left to you, because macOS lets only the person at the Mac approve a driver:

  1. Open System Settings > General > Login Items & Extensions.
  2. Click the (i) beside Driver Extensions.
  3. Turn on org.pqrs.Karabiner-DriverKit-VirtualHIDDevice.

Then vhid doctor prints ready, or names the step still to take. The README has the rest: what the pkg installs and how to remove it.

Give it to an agent

In Claude Code, once vhid is installed:

/plugin marketplace add promptctl/vhid
/plugin install vhid@vhid

The plugin adds vhid and eyes as MCP servers and teaches the agent to look, act, and look again. docs/mcp.md covers other clients and the screen permissions.
